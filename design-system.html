A comprehensive black & white design system combining bold typography, elegant motion design, and refined UI components. It draws inspiration from modern portfolio aesthetics and creative studio design patterns.
The system uses Bricolage Grotesque for headings, Inter for body text, and Space Grotesk for monospace/code elements. All fonts are loaded via Google Fonts CDN with display: swap for optimal performance.
Animations use a combination of CSS @keyframes and Intersection Observer API for scroll-triggered reveals. The system includes fade, scale, blur, slide, and spring-based animations with configurable easing curves inspired by Framer Motion.
